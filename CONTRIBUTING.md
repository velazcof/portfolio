## Commit Messages

feat:       new feature
fix:        bug fix
docs:       documentation only
style:      formatting/style changes with no logic change
refactor:   restructure code without changing behavior
test:       add or update tests
chore:      maintenance/tooling/dependencies
build:      build system/dependency changes
revert:     revert a previous commit

### Examples:

- feat: add projects section
- fix: correct mobile navbar spacing
- docs: update project scope


## Branch Naming

feature/      new feature or visible functionality
fix/          bug fix
refactor/     internal code restructuring
docs/         documentation changes
style/        visual/CSS-only changes
test/         tests
chore/        tooling, dependencies, config, maintenance

### Example:

- feature/hero-section
- fix/mobile-navbar
- docs/update-product-scope
