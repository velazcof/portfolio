## Problem / goal
Build a polished personal portfolio website that clearly presents my software engineering experience, projects, and technical skills to recruiters.

## Scope
The portfolio may include:

- Home with hero section
- About section
- Professional experience timeline
- Projects showcase
- Technical skills / technologies section
- Contact section
- Links to GitHub, LinkedIn, and other relevant profiles
- Downloadable or viewable resume
- Responsive layouts across desktop, tablet, and mobile
- Light and dark theme
- Custom typography, color system, spacing system, and reusable UI components
- SEO metadata and social sharing previews
- Performance optimization
- Image and font optimization
- Contact form
- Custom domain
- Ongoing refinement as new projects, experience, and skills are added
- Accessibility support

## Out of scope (for now)
- Individual project case-study pages
- Subtle animations and interactive effects
- Project filtering or categorization if useful
- Dynamic project content using local data, MDX, or another suitable approach
- Blog or writing section
